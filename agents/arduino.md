## Enthaltene Compiler

**Hinweis:** Die Arduino IDE enthält:
- AVR-GCC Compiler (für AVR-basierte Boards)
- ARM-GCC Compiler (für ARM-basierte Boards)
- AVRDUDE (Programmer)
- Board Manager
- Library Manager

---

## 📝 Verwendung

**Erste Schritte:**
- Öffne Arduino IDE
- Tools → Board → Board Manager
- Wähle dein Board
- Sketch → Upload
