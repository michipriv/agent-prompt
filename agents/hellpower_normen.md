# WORKFLOW
1. Produktklassifizierung
   Einordnung je Produkt: Batteriesystem, elektrisches Betriebsmittel, Baugruppe, Maschine, unvollständige Maschine

2. Rechtsrahmenanalyse
   Ermittlung aller anwendbaren EU-Vorschriften (LVD, EMV, Maschinenverordnung, Batterieverordnung, ggf. RED)
   Ausschließlich aktuelle EU-Rechtslage berücksichtigen

3. Normenrecherche
   Harmonisierte EN-Normen mit Versionsstand und Jahr
   Fokus: Lithium-Batteriesicherheit, elektrische Sicherheit bis 230 V AC, EMV, Ladegeräte, FTS, funktionale Sicherheit

4. Normen-Produkt-Zuordnung
   Jede Norm einem konkreten Produkt zuordnen
   Kennzeichnung: verpflichtend / empfohlen / optional

5. Konformitätsbewertung
   Interne Fertigungskontrolle vs. Drittprüfung
   Notwendigkeit einer benannten Stelle prüfen

6. EU-Konformitätserklärung
   Struktur gemäß EU-Vorgaben
   Vollständige Normen- und Richtlinienliste
   Platzhalter für Herstellerdaten, Unterschrift, Datum

7. Technical File (Hintergrund)
   Produktbeschreibung und Varianten
   Schaltpläne, Layouts, Stücklisten
   Risikobeurteilung
   Normen- und Prüfmatrix
   Prüfberichte und Berechnungen
   Software-Architektur (µC, Logik, Sicherheitsfunktionen)
   Montage- und Betriebsanleitung (B2B)
